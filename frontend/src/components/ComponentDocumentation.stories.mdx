# Shared component usage

This Storybook catalog documents shared UI building blocks and their expected usage:

- **Button**: user-triggered actions; choose `variant` based on action priority.
- **Input**: labeled form control with built-in help and error messaging.
- **Modal**: focused dialog for interruptive flows requiring user confirmation.
- **ProgressBar**: compact completion indicator for timers and progression states.

Use each component story's **Args** and **Docs** tabs to review prop descriptions and usage examples.
